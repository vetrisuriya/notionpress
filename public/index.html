Publish your Notion pages to GitHub

Pick a Notion page and a repository. We export the page and all its sub-pages as clean HTML or Markdown and commit them to the branch you choose. Run it by hand or keep it in sync every hour or day.

How it works

You sign in with Notion and share only the pages you want. You install the GitHub app on the repositories you want. Each sync updates only the pages that changed and writes everything in one commit.

Because the sync runs on our side, you only need GitHub access afterwards. That helps on networks that block Notion sign-in.
